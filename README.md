# react-course-chatbot
A React-based AI chatbot designed to answer questions using provided course and support materials.
Course Support Bot

A web-based chatbot interface built with **React.js and Vite**. It is built to assist users in navigating course and support materials via a simple and intuitive chat interface. 

 ## Project Description

I developed this project as a part of my internship. It is an interactive chatbot to access and work with course/support information.

The app offers a clean and user-friendly environment for users to send messages and view conversations in a manner similar to a ChatGPT interface.

 ## Features
 
 Interactive chat interface
 User and chatbot messages
 Conversation history
 Designed to work with course/support materials
 Clean and responsive user interface
 Fast development environment using Vite

## Getting Started
1. Clone the repository
git clone https://github.com/YOUR-USERNAME/course-support-chatbot.git
2. Navigate to the project
cd course-support-chatbot
3. Install dependencies
npm install
4. Start the development server
npm run dev

The application will then be available at the local URL provided by Vite.

## Project Goals

The main goals of this project are to:

Create a modern chatbot interface using React
Practice component-based development
Manage conversations and chat history
Create an interface that can later be connected to an AI model
Explore how course/support materials can be integrated into a chatbot
